# Gemini OCR

Press `Cmd+Shift+S`, capture a region, and paste extracted text.

## Setup

1. Open the controller menu
2. Enable `Gemini OCR`
3. Set `Gemini API Key` in the `Secrets` section
4. Grant screen recording permission to Hammerspoon if macOS asks

## Storage

Settings, secrets, prompt overrides, and hotkey overrides live in `packages/gemini/gemini.json`.
